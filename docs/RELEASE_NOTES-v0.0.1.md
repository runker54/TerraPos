# Release Notes — v0.0.1

首个版本。

## 新增

- **8 类地形部位自动划分**：山间盆地、丘陵上/中/下、山地坡上/中/下
  （西南区口径，宽谷盆地编码保留）；
- **地貌亚类栅格**：低丘/高丘/低山/中山/高山/极高山/平坝；
- **Rust 桌面应用**（Windows x64 便携版）：
  - DEM 导入 → 参数调优 → 后台计算（分阶段进度/取消）→ 结果预览 → 导出；
  - 参数全部可调：坝子最低宽度、坡度阈值、山体单元窗口、阶地修正、
    丘陵海拔上限、后处理强度等；
  - 预览支持图层切换（部位/亚类）、鼠标锚点缩放、拖拽平移、浮动图例、
    山体阴影底图；
- **Python 基准实现**：arcpy+scipy 参考脚本（`python/`），
  与 Rust 结果对拍一致率 **97.17%**；
- **算法**：Priority-Flood 填洼(z-limit)、D8 汇流、
  精确欧氏 EDT(Meijster 两遍扫描, 含最近源索引)、
  峰顶提取(局部极大 + 窗口严格突出度 + 等值平台质心收缩 + NMS)、
  marker watershed(从高到低淹)山体单元、逐像元宽度核心化坝子识别；
- **山体个体分割五种可选策略**（`SeedMode`，默认单一窗口）：
  单一固定窗口 / 分亚类动态窗口 / 地形突起度(prominence) /
  多尺度 TPI 特征尺度投票 / 混合(突起度∪距离)；
  策略对比实验与结论见 `docs/seed_mode_comparison.png`。
