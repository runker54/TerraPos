# TerraPos v0.0.1 发布说明

## 本版核心变化: 自适应 DEM 地形部位划分(全面替换旧固定窗口方案)

只依赖一份投影米制 DEM(CGCS2000 3度带等), 运行时不需要河流、流域、
土地利用或训练样本。有效输出 7 类: 1=山间/宽谷盆地, 3/4/5=丘陵
上/中/下, 6/7/8=山地坡上/中/下; 0=NoData 全程保留; 2 为保留码,
任何成果生成计数必须为 0。

### 算法管线(12 阶段)

1. 输入校验: Float32 + 投影米制 CRS(GeoKey 1024=1/3076=9001),
   正方形正分辨率; 边界连通 NoData 永久保留; <=0.01km2 内部孔
   按最近有效值填补; valid-aware 圆形均值地貌表面。
2. 双表面: 地貌表面(保形平滑)与水文表面(有界 Priority-Flood,
   z-limit=15m, 超限深洼保留为内流区并输出修正深度层)。
3. 水文骨架: 25m 粗层 D8 路由 + 四级嵌套河网(0.05/0.2/1/5 km2
   物理汇水面积)+ HAND(沿 flow_to 链至首个河网, 深洼独立锚)。
4. 多尺度金字塔: 米制尺度族 125-4000m, 稳健 DEV/H(P95-P05)/
   NDEV/IQR, 增长率收敛+H>5m 选择特征尺度 R0。
5. geomorphon 十标准形态(flat/peak/ridge/shoulder/spur/slope/
   hollow/footslope/valley/pit, 旋转镜像不变), 按特征尺度采样。
6. 脊线: 河链集水区竞争泛洪边界(排除河旁伪边界与 NDEV<=0 伪
   接触) + 反地形汇流(P95 分位)/NDEV/形态三分量补充证据。
7. 坡面单元: 谷/脊双屏障 + 坡向 8 扇区相容(<=90 度)泛洪 +
   子流域约束; <4 像元小单元并入最长边界邻居。
8. 约束几何: 多源 Dijkstra(坡向无向差正弦代价, 跨单元禁止),
   dv/dr 锚点 + 逐河网等级 L_k 选择 R*=clip(0.5L, 亚类上下限);
   HAND + 低起伏权重(lerp 0.45->0.75)融合相对位置 q。
9. 模糊隶属度: Logistic/高斯隶属 + 形态证据(规格 10.2 表)+
   曲率修正; 置信度=最大-次大(低置信 *0.6)。
10. 盆地对象: 低平候选(下部证据+q<0.45+亚类坡度上限+微起伏
    IQR+HAND/洼地+三尺度保持) -> 按谷底集水区聚合 -> 宽度核心
    -> 面积/宽度/核心/内起伏/方向围限(16 方向 60%)/水文连通或
    闭合洼地多重检验 -> 从核心在候选域内 geodesic 重建完整边界。
11. 组合: 盆地=1 -> 丘陵(<500m)/山地 -> 3-8; 亚类独立编码 1-7
    (含高丘细分); 受约束清理: 单元内小斑归并(不跨脊/谷/盆/无效/
    丘山界)+ 脊->谷轨迹三态单调 DP(仅低置信且总代价改善)。
12. 类别最近邻+连续双线性上采样回原生分辨率, 恢复原生 NoData;
    写出 4 类正式成果与 11 个诊断层(class_report.txt 含面积/对象
    /低置信/修正数/阶段耗时, 并声明保留码 2 计数必须为 0)。

### 验证结果(data/synthetic 13 个解析场景 + data/dem.tif)

- 码域/保留码/NoData: 全部场景 0 违规; 真 DEM 保留码 2 计数=0。
- 变体稳定性: 25m 回采样一致率 0.948(门 0.85)、0.5m 噪声 0.945
  (门 0.90)、90 度旋转 0.955、镜像 1.000、垂直平移 1.000。
- ±20% 参数扰动(basin_min_area/postprocess/z_limit): 类面积与
  盆地面积变化 0.000(门 0.15/0.20)。
- 真 DEM(14831x9058@5m, 3358.5km2): 山地坡上 42.28%/坡中
  29.87%/坡下 27.85%, 山间/宽谷盆地 0.26km2; 全区高程
  626.8-1689.4m 均高于 500m, 丘陵类(3-5)按业务口径合法缺席。
- 合成场景特征尺度跨 5/10/25m 采样漂移<=1 尺度步; 几何相同的
  宽/窄地貌分别选择更大/更小分析尺度; 高程平移不变量逐像元成立。

### 已知限制(如实披露)

- 部分合成场景(宽盆 0.65/V 谷 0.51/闭合洼地 0.17)的脊->谷轨迹
  单调率未达 95% 验收线: 这些场景的坡位界线受锚点切换与
  persist 大窗语义影响存在空间破碎; 嵌套山脊(真实地貌) 0.998
  达标。合成场景无人工真值, 不据此声称真实精度。
- 山间/宽谷盆地面积在当前对象判据下偏保守(hhgq 0.26km2);
  盆地保留倾向(严格/标准/宽松)可在界面调整。
- 深洼爬升边切断使少数外坡像元 HAND 为 NoData(低置信标记)。

### 桌面应用

- 参数只暴露可解释项: 分析精细度(快速/标准/精细)、盆地保留倾向
  (严格/标准/宽松)、最小盆地面积(亩)、后处理强度(弱/标准/强)、
  诊断开关; 研究模式高级面板暴露粗层分辨率/z-limit/尺度收敛阈/
  低起伏判据/丘陵上限/河网四级面积。
- 运行后可预览: 最终坡位、地貌亚类、置信度、自适应尺度、HAND、
  相对位置 q、盆地重建(灰度懒加载)。
- 任一界面参数都有自动测试证明其改变了对应中间量或结果
  (tests/parameter_effects.rs)。
